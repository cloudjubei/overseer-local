Generated Backend API Client

This directory is the output of openapi-typescript-codegen.
Do not edit files here manually; they will be overwritten.

Regenerate the client whenever swagger.json changes:
- npm install
- npm run generate:backend

Generator options:
- client: axios
- useOptions: true (methods accept typed options including headers)

Environment/configuration:
- Base URL and auth token can be configured at runtime using the helper in src/lib/backendClient.ts.
